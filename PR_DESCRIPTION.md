## Technical Details

### Specifications Met
- ✅ PNG-24 with alpha transparency
- ✅ File size: All avatars <5KB (most <400 bytes!)
- ✅ Sprite sheet: 384x32px layout (12 agents × 4 frames)
- ✅ CSS: `image-rendering: pixelated` for crisp scaling
- ✅ Support sizes: 32px, 64px, 128px via CSS scaling
- ✅ 4-frame idle animations @ 8fps (200ms per frame)

### Animation Types
- **Bobbing**: Jelly-Legs, Data-Diver, Pattern-Seeker
- **Breathing**: Build-Bot, Shield-Bot, Pipe-Layer
- **Floating**: Hook-Maker, Launch-Pad, Code-Crafter
- **Pulsing**: Voice-Weaver, Sketch-Bot, Map-Maker
